# Project Detail Page

Each project should behave like a case study.

Possible sections:

## Hero

- project title
- description
- status
- technologies
- project image

## Overview

What the project is.

## Problem / Motivation

Why the project exists.

## Development

How the project is being built.

## Technical Decisions

Architecture, tools and important implementation decisions.

## Progress

Completed, current and upcoming work.

## Gallery

Screenshots, mockups or development images.

## Challenges

Interesting technical or design problems encountered.

## Lessons Learned

What was learned while developing the project.

## Development Log

Each project can contain chronological development entries.

Each entry may include:

- date
- title
- short update
- screenshots
- technical notes
- related technologies
- tags

## Next Steps

What is planned next.

## Links

GitHub or other relevant project links.

# Design Principles

The website should feel:

- personal
- technical
- editorial
- modern
- clean
- professional

Use:

- strong typography
- generous whitespace
- large project visuals
- asymmetrical layouts where appropriate
- subtle visual personality
- light and dark themes

Avoid:

- generic portfolio templates
- rows of identical cards
- skill percentage bars
- excessive gradients
- excessive animations
- Matrix / hacker aesthetics
