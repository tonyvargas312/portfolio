# Anthony Vargas Portfolio

Personal portfolio website built with React, TypeScript and Vite.

The website is intended to showcase:

- software projects
- data-related projects
- game development work
- university projects
- certifications
- education
- resume
- GitHub
- LinkedIn
- professional contact information

## Project philosophy

This site is designed as a personal technical website rather than a traditional one-page portfolio.

Projects are presented in a case-study style, allowing visitors to explore the development process, technical decisions, progress and lessons learned.

## Development

Install dependencies:

    npm install

Start the development server:

    npm run dev

Build for production:

    npm run build

Run the linter:

    npm run lint

## Vercel deployment

Import this repository through the Vercel dashboard using the **Vite** framework
preset. Use the repository root, build command `npm run build`, and output
directory `dist`. No environment variables are required.

The root `vercel.json` provides the SPA fallback needed by React Router for
direct navigation and refreshes on application routes. Vercel serves existing
static files, including Vite's generated images and resume PDF, directly.

For a local production check, run `npm run build` followed by `npm run preview`.
The resume asset URL is generated by Vite; the download links preserve the
filename `Anthony_Vargas_Arguedas_CV.pdf`.
